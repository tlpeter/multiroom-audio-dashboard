# Multiroom Audio Dashboard 2.2.0-beta.4

**Save your own equalizer settings with a name.** Under the built-in EQ profiles there is now a **Mijn profielen** section: set the sliders, type a name and press **Huidige instelling opslaan**. The profile appears as a button and can be applied later with one click, also on another board with the same 15 bands. (#23)

- Saving only reads the current slider states; it sends nothing to the speaker.
- Applying a saved profile uses the same checks as the built-in profiles: every band must be available and within its range, only changed bands are sent, the EQ is switched on, and it stops on the first failure.
- Saving under an existing name updates that profile. Built-in names are refused. Up to 24 profiles, names up to 40 characters. Delete with × and confirm.
- Profiles are stored in your Home Assistant user account (frontend user data), so they follow you across browsers and devices with the same HA user. Another HA user does not see them.

Tested automatically with synthetic Home Assistant states (unit and browser tests, desktop and mobile). Not yet verified on a live Home Assistant with a physical Louder-ESP32 board.

Update through HACS and reload the browser. Existing speaker, EQ and appearance configurations remain compatible.
