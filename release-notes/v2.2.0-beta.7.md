# Multiroom Audio Dashboard 2.2.0-beta.7

**Track info for Sendspin speakers.** ESPHome Sendspin players (for example a Louder-ESP32 with the Sendspin firmware) do not put the title on the media player; they expose it as the sensors **Track Title**, **Artist** and **Album** on the same device. The card now finds these sensors automatically and shows title, artist and album in *Nu aan het spelen*. With *Online info over het nummer* on, the card can then also look up the year, artist text and a cover. (#29)

- Media player information still wins when present. Empty, unknown or unavailable sensor values are ignored.
- These sensors carry no album art; a cover only comes from online info (Cover Art Archive).
- `auto_entities: false` turns this off together with the other automatic entity discovery.

Tested automatically with synthetic Home Assistant data (unit and browser tests). Not yet verified on a live Sendspin speaker.

Update through the Home Assistant Marketplace and reload the browser.
